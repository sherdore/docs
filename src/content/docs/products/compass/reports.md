## The report

A finished analysis opens as a side-by-side report: one table per dimension, you against each competitor, with the leader marked on every row.

The report ends with a **ranked list of fixes**. Each one names the problem, who is already ahead on it and gives a short how-to. Critical problems always surface.

## Share it

Every finished analysis has its own **public link**. Anyone with the link can read the report without logging in, which makes it easy to send to a client or a colleague.

## Export

Download the comparison as a **CSV** to use in your own slides or spreadsheets. You can export a single report, or the whole **Analyses** list.
