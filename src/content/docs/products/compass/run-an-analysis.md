## Start one

1. Open **Analyses** and choose **new analysis**.
2. Enter your own **domain** and, optionally, a **label** to help you find it later.
3. Choose competitors from your saved list, or type new ones in.
4. Start the analysis.

Compass audits your site and every competitor in one run. It can take a little while, because it crawls each site and asks Google for performance data.

## Status

| Status | Meaning |
|---|---|
| **Pending** | Waiting to start. |
| **Running** | Being audited now. |
| **Completed** | Every site was audited and scored. |
| **Partially failed** | Some sites couldn't be audited. The report says which and why, and scores the rest. |
| **Failed** | None could be audited. |

## Limits

Each run counts toward your plan's analyses for the month, and your plan sets how many competitors you can compare. See the [plans](/products/compass/#plans).

## Run it again

Re-run an old analysis in one click. Compass checks the same domains again and picks up anything that has changed, including newly added recommendations.
