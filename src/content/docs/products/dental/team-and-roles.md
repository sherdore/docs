People join your organization through your SherDore account. See [Your team](/getting-started/team-and-organizations/). Inside Dental, each person has one of five roles, and the **Team** page lists everyone and lets an owner or office manager change a role.

## Roles

| Role | Typical person |
|---|---|
| **Owner** | The practice owner. |
| **Office manager** | Runs the front desk and admin. |
| **Dentist** | Treats patients. |
| **Hygienist** | Hygiene and recall care. |
| **Billing** | Handles invoices and payments. |

## What each role can do

| Area | Owner | Office manager | Dentist | Hygienist | Billing |
|---|:-:|:-:|:-:|:-:|:-:|
| Team and organization settings | ✓ | ✓ | | | |
| Patients | ✓ | ✓ | ✓ | ✓ | |
| Leads | ✓ | ✓ | ✓ | ✓ | |
| Recurring plans | ✓ | ✓ | ✓ | ✓ | |
| Treatments | ✓ | ✓ | ✓ | | |
| Estimates | ✓ | ✓ | ✓ | | |
| Invoices and payments | ✓ | ✓ | | | ✓ |

## Settings

Owners and office managers set the practice's defaults under **Organization settings**: default tax rate, default terms and how long an estimate stays valid.
