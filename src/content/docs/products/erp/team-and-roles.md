People join your organization through your SherDore account. See [Your team](/getting-started/team-and-organizations/). Inside ERP, each person has one of three roles.

| Area | Owner | Manager | Staff |
|---|:-:|:-:|:-:|
| Organization settings | ✓ | | |
| Team | ✓ | ✓ | |
| Invoices and payments | ✓ | ✓ | |
| Recurring plans | ✓ | ✓ | |
| Leads | ✓ | ✓ | ✓ |
| Estimates | ✓ | ✓ | ✓ |
| Properties | ✓ | ✓ | ✓ |

## How roles start

The first time someone opens ERP, their account role chooses where they start. An owner can change it afterwards.
