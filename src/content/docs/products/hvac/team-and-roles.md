People join your organization through your SherDore account. See [Your team](/getting-started/team-and-organizations/). Inside HVAC, each person has one of five roles, and the **Team** page lists everyone and lets an owner or office manager change a role.

## Roles

| Role | Typical person |
|---|---|
| **Owner** | The business owner. |
| **Office manager** | Runs the office day to day. |
| **Dispatcher** | Books and assigns the work. |
| **Technician** | Does the work in the field. |
| **Accountant** | Looks after the books. |

## What each role can do

| Area | Owner | Office manager | Dispatcher | Technician | Accountant |
|---|:-:|:-:|:-:|:-:|:-:|
| Team and organization settings | ✓ | ✓ | | | |
| Technicians | ✓ | ✓ | ✓ | | |
| Leads | ✓ | ✓ | ✓ | | |
| Parts and stock | ✓ | ✓ | ✓ | | |
| Equipment | ✓ | ✓ | ✓ | ✓ | |
| Estimates | ✓ | ✓ | ✓ | ✓ | |
| Maintenance plans | ✓ | ✓ | ✓ | ✓ | |
| Invoices and payments | ✓ | ✓ | | | ✓ |

## How roles start

The first time someone opens HVAC, their account role chooses where they start. You can change it afterwards on the **Team** page.
