## API keys

Open **API keys** to let another system talk to Outreach. Give each key a **name** and choose the **scopes** it may use, so a key can do only what it needs. Delete a key to cut off anything using it.

Treat a key like a password: keep it on your server and never in browser code.

## Team

People join your organization through your SherDore account. See [Your team](/getting-started/team-and-organizations/). Inside Outreach each person is an **Owner**, **Manager** or **Member**. The first time someone opens Outreach, their account role decides where they start.
