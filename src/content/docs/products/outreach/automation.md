An automation workflow runs on its own for each contact it applies to.

## Steps

| Step | What it does |
|---|---|
| **Wait** | Pauses for a number of **hours** or **days**. |
| **Send email** | Sends an email you've written. |

For example: send a welcome email, wait 3 days, send a follow-up.

## Triggers

| Trigger | When it starts |
|---|---|
| **Contact added to a list** | A contact joins the list you chose. |
| **Manual** | You start it for the contacts you pick. |

## Status

| Status | Meaning |
|---|---|
| **Draft** | Being built. Nothing is sent. |
| **Active** | Running. |
| **Paused** | Stopped for now. |

## Tracking

Each contact's run through a workflow is tracked as **Pending**, **Completed** or **Failed**, so you can see where anyone is.
