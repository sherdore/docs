## Build a campaign

Open **Campaigns** and create one. Choose the list to send to, write the message (or start from a [template](/products/outreach/contacts/#templates)) and review it.

## Status

| Status | Meaning |
|---|---|
| **Draft** | Being written. Nothing is sent. |
| **Scheduled** | Set to send at a time you chose. |
| **Sending** | Going out now. |
| **Sent** | Finished. |

## Send now or schedule

Choose **send** to start straight away, or **schedule** and pick a future date and time. You can **unschedule** a campaign to pull it back to a draft.

## A/B testing

Write two versions of a campaign, **A** and **B**, and compare how each performs. When you're ready, **declare a winner** to pick the version that worked better.

## Tracking

For every recipient, Outreach records what happened:

| Result | Meaning |
|---|---|
| **Pending** | Not sent yet. |
| **Sent** | Handed to your email provider. |
| **Opened** | The recipient opened it. |
| **Clicked** | They clicked a link. |
| **Bounced** | It couldn't be delivered. |
| **Complained** | They marked it as spam. |
| **Failed** | Sending failed. |

The campaign page shows totals, results per version and insights. If some recipients failed, use **retry failed** to send to just those.
