Paste a URL on the **Free SEO Check** page and get a scored report on the on-page basics. You don't need an account.

## What it checks

| Check | What it looks for |
|---|---|
| **Title tag** | Present, and in the ideal 30 to 60 character range. |
| **Meta description** | Present, and in the ideal 120 to 160 character range. |
| **H1 and headings** | Exactly one H1 and no skipped heading levels. |
| **Image alt text** | Coverage across every image on the page. |
| **Canonical tag** | Present, so search engines know the source of truth. |
| **Robots meta** | Not accidentally blocking indexing. |
| **Viewport and mobile** | Set up for mobile rendering. |
| **HTTPS** | Served securely. |
| **Word count** | Enough real content to rank on. |

The check runs against the live page, using real HTML parsing, not a cached template. Every issue is explained in plain language, with why it matters and how to fix it.
