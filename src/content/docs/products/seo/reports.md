## Add a website

Open **Websites** and add a site. Your plan sets how many you can add.

## Run a report

From a website, run a report. A **single** scan checks one page. A **site** scan checks multiple pages, and is available on every paid plan.

Each report counts toward your plan's reports for the month. If you've used them all, you'll be asked to upgrade.

## Read it

A report is a scored list of what was checked, with each problem explained and how to fix it. Download a report as a **PDF** to share.

## White-label

On Pro and Agency, reports carry **your own branding** instead of ours. Set your brand name and logo under **Settings**. See [Plans and features](/products/seo/plans-and-features/).
