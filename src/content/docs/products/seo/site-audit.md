Site Audit starts from your homepage, follows your internal links, and checks every page it finds. It lists every broken link, missing title and slow page, with how to fix each.

## Run an audit

1. Open **Site Audit** and choose a website.
2. Start the audit and watch its status as it crawls.
3. When it finishes, open the results.

## Limits

Your plan sets how many audits you can run per month and how many **pages** each audit checks. It stops at the page limit. See the [plans](/products/seo/#plans).

## The results

Issues are grouped into six categories and listed with a code you can open. Open an issue to see **every page it affects**, and open a page to see everything found on it.

## What it can and can't see

Site Audit reads the HTML your server sends. Content added later by JavaScript shows up as thin pages.
