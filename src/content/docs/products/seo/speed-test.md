Speed Test runs Google Lighthouse on any public page, on **mobile** or **desktop**.

## What you get

- the **performance**, **accessibility**, **best-practice** and **SEO** scores
- the **Core Web Vitals**
- real-visitor data, when Google has it for that page
- a list of what to fix

## Run one

1. Open **Speed Test** and enter the page's address.
2. Choose mobile or desktop.
3. Start the test. It runs in the background and the page updates when it's done.

Each test counts toward your plan's speed tests for the month.

## What it doesn't do

It doesn't run from several locations and it doesn't show a request waterfall.
