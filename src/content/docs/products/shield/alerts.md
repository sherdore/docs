Alerts tell you when something needs attention, without you having to open the portal.

## Channels

Alerts reach you by **email** or **webhook**. Slack, Discord and Telegram are planned.

## Events

Choose which events trigger an alert:

| Event | When |
|---|---|
| **Website down** | A site stops responding. |
| **Website back up** | A site that was down recovers. |
| **SSL expiring** | A certificate is close to expiring. |
| **Domain expiring** | A domain is close to expiring. |
| **Vulnerability found** | A new vulnerability is detected. |
| **Malware found** | The agent finds malware. |
| **File integrity found** | A file was added, changed or removed. |
| **Site Scan found** | Site Scan finds a new issue. |

## Delivery

Each alert's delivery is recorded as **sent** or **failed**, so you can see whether it reached you. Open **Alerts** in the portal for the list.
