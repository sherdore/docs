Each page is built from **blocks** that you stack in the order you want. There's no code to write.

## Add blocks

Open a page and use **Add block** to add any of these:

| Block | What you set |
|---|---|
| **Heading** | The text, the heading level (such as H2) and the alignment. |
| **Text** | The text and the alignment. |
| **Image** | The image address (a `https://` URL) and its alt text. |
| **Button** | The button text, the link it goes to, and its style. |
| **Spacer** | The gap size, such as medium. |

## Arrange and edit

- **Drag** a block to move it up or down the page.
- Edit a block right where it sits.
- **Remove** a block you no longer want.

## The page address

Each page has a **title** and a **slug**, the part of its address after the site's domain. The homepage's slug is fixed.

## Save, publish or delete

- **Save** keeps your changes without making them public.
- **Publish** makes the page live. See [Publish](/products/sites/publishing/).
- **Delete page** removes it permanently, so you're asked to confirm. The homepage can't be deleted.

Pages you wrote with an earlier, plain-text editor are carried over as a single text block.
