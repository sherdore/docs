Open **Media** to upload files. Once uploaded, you can attach them to any post.

## Accepted files

| Kind | Formats |
|---|---|
| **Images** | JPG, PNG, GIF, WebP |
| **Video** | MP4, MOV |

Each file can be up to **50 MB**.
